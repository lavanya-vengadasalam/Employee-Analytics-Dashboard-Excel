# Employee Analytics Dashboard using Excel

## Project Overview
This project presents an interactive Employee Analytics Dashboard built using Microsoft Excel to analyze employee data and generate meaningful workforce insights.

The dashboard helps summarize employee demographics, salary and compensation, performance, and work experience through KPI cards, PivotTables, formulas, and charts.

## Project Objectives
- Analyze employee headcount and workforce distribution.
- Understand salary and bonus distribution across departments.
- Evaluate employee performance scores and ratings.
- Explore employee experience, education, work modes, and joining trends.
- Present key findings through clear and professional dashboards.

## Tools and Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and functions
- Data cleaning and validation
- Charts and KPI cards

## Dataset
The project uses a sample dataset containing 50 employee records.

The data includes employee details, department, job title, location, work mode, joining year, experience, annual salary, bonus, performance score, education, projects, and leave balance.

## Dashboards

### 1. Employee Overview
- Total employee count
- Total annual salary
- Average annual salary
- Total projects
- Employee distribution by department, work mode, and state

### 2. Salary and Compensation
- Total and average annual salary
- Highest annual salary
- Total bonus amount
- Salary analysis by department and salary band

### 3. Performance Analysis
- Average and highest performance scores
- Employees meeting the performance target
- Employee count by performance rating
- Average performance score by department
- Top 10 employees by performance score

### 4. Workforce and Experience
- Total employees
- Average employee experience
- Active employee count
- Department count
- Analysis by experience band, work mode, education level, and joining year

## Key Skills Demonstrated
- Data cleaning and validation
- Data analysis and summarization
- Excel formulas and functions
- PivotTable and PivotChart creation
- Dashboard design and data visualization
- Reporting and business insights

## Project Outcome
Built a four-dashboard Excel analytics solution that organizes employee data into clear visual summaries to support workforce, compensation, and performance analysis.
